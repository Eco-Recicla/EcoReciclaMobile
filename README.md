# EcoRecicla Mobile — EcoRutas

Aplicación móvil Android desarrollada en Kotlin Multiplatform (KMP) con Compose, Ktor, SQLDelight y persistencia offline-first para el registro y pesaje de rutas de reciclaje.

> **Arranque técnico:** Repositorio inicializado para el Examen Parcial Unidad 2 (Versión B - Caso EcoRecicla). Todo el desarrollo funcional se realiza en ramas de funcionalidad e integración sobre `develop`.
